## V1.44: 기계 프로파일 / 가공 셋업

상단에서 이름을 선택하면 해당 기계 또는 가공 셋업을 바로 불러옵니다. `프로파일 관리`는 설정 탭의 관리 화면을 엽니다. 현재 입력값을 `새 이름 저장`으로 추가하고, 이후 `저장`으로 갱신하거나 이름을 바꾸고 삭제할 수 있습니다. 상단의 `*`는 저장값과 현재값이 다름을 뜻합니다. 선택 시 현재 입력값이 바뀌므로 보관할 수정값은 먼저 저장하세요.

- 기계 프로파일: START/END, 어니언스킨 전용 START/END, G53 주차 사용·좌표, 중간 교체 매크로·복귀 Z·대기 시간.
- 가공 셋업: 공구·RPM·피드·판 두께·Z 기준·패스·탭·포켓·정삭·보정·교체 사용/거리 등. 형상·수동 탭 위치·배치·판재 X/Y·XY 원점·화면 설정은 유지합니다.
- 첫 실행 시 기존 입력값을 `기존 기계`와 `기존 가공 셋업`으로 보관합니다. 이름을 바꿔서 사용하세요. 프로파일은 실행 폴더의 `profiles.json`에 저장하며 새 파일을 만들 수 없는 폴더에서는 AppData에 보관합니다. 개인 설정과 함께 공개 Git에서는 제외합니다.
- 작업 파일은 저장 당시 실제 값과 코드를 계속 포함합니다. 프로파일을 나중에 수정해도 이전 작업의 값은 바뀌지 않습니다. 프로파일 적용 후에는 G-code를 다시 생성해야 합니다.

기계별 코드를 실행하거나 실제 장비를 검증한 것은 아닙니다. 변경한 프로파일로 생성한 NC의 원점·Z 기준과 START/END를 확인하고 공중 드라이런을 하세요.

## V1.43: 배치된 파츠를 판재 전체로 등간격 확장

`판재 전체에 외곽 박스 등간격 배치`는 이미 놓은 파츠의 줄·열 관계를 유지하면서, 판재 가장자리와 파츠별 외곽 여유를 남기고 파츠 사이 간격을 가능한 크게 벌립니다. V1.42에서 파츠가 한쪽으로 좁게 모이던 동작을 수정했습니다. 판재에 들어가지 않으면 기존 배치를 유지하며 Ctrl+Z로 되돌릴 수 있습니다.

## V1.42: 빠른 작업 불러오기·공구 중심선 참고·배치 간격 정리

큰 작업 파일을 열 때 중복 화면 갱신을 제거했습니다. 기본 화면은 공구 지름과 내·외경 보정을 반영한 중심선 참고선만 표시하고, 상세 경로 생성과 충돌 검사는 `G-code 생성`에서 수행합니다. `현재 배치 외곽 박스 간격 정리`는 이미 배치한 파츠의 사각 외곽을 기준으로 간격을 맞추며, 파츠별 외곽 여유·판재 경계를 검사하고 Ctrl+Z로 복원할 수 있습니다.

이 버전은 G-code 생성 및 선택형 G2/G3 출력 방식을 바꾸지 않습니다. Mach3에서 원호 경로 표시가 느리면 `윤곽 원호 G2/G3 사용`을 끈 파일과 불러오기 시간을 비교하세요.

## V1.41: 선택형 윤곽 원호 G2/G3

왼쪽 `윤곽 원호 G2/G3 사용`을 켜면 일정 깊이의 윤곽에서 원호로 확인된 구간을 Mach3의 증분 I/J 원호로 출력합니다. 경로 허용오차와 출력 좌표의 반지름을 확인한 구간만 변환하며, 탭 경사·깊이 변경·포켓 경로는 기존 G1을 유지합니다. 기본값은 꺼짐이고 구버전 작업도 꺼진 상태로 열립니다. 실제 절삭 전 생성 NC의 원호와 이동을 확인하고 공중 드라이런을 하세요.

## V1.40: 깊이 가공 우선 순서·외곽 다중 드래그

왼쪽 `깊이 가공 우선 (보어 → 내경 → 외경)`을 켜면 활성 윤곽을 **포켓·보어 → 깊이 지정 내경(얕은 깊이부터) → 일반 관통 내경 → 열린 경로 → 외경** 순서로 가공합니다. 각 단계 안에서는 기존 수동 순번과 이동 최적화·외곽 자동 순서를 유지합니다. 다른 단계에 지정한 수동 순번보다 이 단계 순서가 우선합니다. 보어나 깊이 지정 내경이 없으면 기존 순서와 같습니다.

기본값은 꺼짐이며 구버전 작업 파일도 꺼진 상태로 엽니다. 윤곽 목록·2D 미리보기·예상 거리/교체 계획·생성 NC에 같은 옵션이 적용되고, NC 헤더에 `DEPTH_FIRST_ORDER`가 기록됩니다. STEP 가져오기에서 해당 형상이 실제 포켓 또는 깊이 지정 내경으로 인식됐는지 목록에서 확인해야 합니다. 실제 절삭 전에는 생성 NC와 공중 드라이런으로 순서를 확인하세요.

윤곽 목록에서 외곽 여러 행을 Ctrl/Shift로 선택하고, 선택된 외곽의 `순서` 또는 이름/Layer 영역을 잡아 드래그하면 선택 외곽이 **현재 목록에 보이는 상대 순서 그대로 한 묶음**으로 삽입선 위치에 들어갑니다. 선택한 외곽 위에 놓거나 목록 밖에 놓으면 순서가 바뀌지 않습니다. 내부/포켓 윤곽은 외곽 순서 드래그 대상이 아닙니다. 목록에서 선택만 바뀔 때는 화면 형상을 다시 생성하지 않고 기존 선의 강조만 갱신합니다. 순서 변경은 Ctrl+Z로 되돌릴 수 있습니다.

## V1.39: 시작점 방향 표시와 5분 작업 임시 저장

지정 시작점의 자주색 화살표와 2D 공구 경로가 실제 외곽/내곽 절삭 진행 방향을 표시합니다. Climb milling 설정을 바꾸면 즉시 갱신됩니다. 생성 NC의 절삭 경로는 바뀌지 않습니다.

작업 중 5분마다 변경된 상태를 `%APPDATA%\CFRP_Router_CAM\autosave`에 별도 파일로 저장합니다. 비정상 종료 뒤 다시 실행하면 최신 임시 작업의 복구 여부를 묻습니다. 정상적으로 작업을 저장하거나 종료하면 해당 임시 파일을 정리합니다. 원래 `.cfrpcam` 파일은 자동 저장으로 덮어쓰지 않습니다. 종료 시 변경된 작업이 있으면 저장 여부를 묻고, 아직 작업파일이 없다면 날짜 이름의 저장 창을 엽니다.

## V1.38: 전체 판재 중앙 기준으로 외곽 순서 수정

`중앙 → 바깥 (시계/반시계)`는 왼쪽 어레이 설정의 **판재 X÷2, 판재 Y÷2**를 기준으로 가까운 거리층부터 외곽을 가공합니다. 판재 좌하단은 배치 좌표 (0,0)이며 G54/선택 원점과 별개입니다. 한쪽에만 파츠를 배치해도 파츠 범위로 중심을 다시 잡지 않습니다. 판재 크기를 수정한 뒤 Enter 또는 다른 항목으로 이동하면 목록·미리보기 순서를 갱신하고, 다음 NC 생성/저장에 새 기준을 반영합니다. 내부 홀/포켓 및 수동 지정 순번은 우선하며 각 윤곽의 절삭 방향은 유지합니다.

V1.37은 파츠 배치 범위의 중심을 사용했으며 V1.38에서 전체 판재 기준으로 바로잡았습니다. 생성한 코드의 `OUTER_ORDER_REFERENCE: SHEET_CENTER`와 `OUTER_ORDER_CENTER_SOURCE_X/Y_MM` 주석에서 배치 좌표 기준 중심을 확인할 수 있습니다. 기존 작업을 열면 저장된 판재 X/Y가 적용되므로 실제 판재 크기를 확인하고 코드를 다시 생성하세요.

## V1.37: 중앙부터 바깥으로 외곽 가공

왼쪽 `외곽 자동 가공 순서`에서 `가까운 순서`, `중앙 → 바깥 (시계)`, `중앙 → 바깥 (반시계)`를 선택합니다. 배치된 활성 외곽 전체 영역의 중심을 기준으로 가까운 거리층부터 가공하고, 각 층은 12시(+Y)부터 지정 방향으로 방문합니다. 거리층 폭은 외곽 중심들의 최근접 간격 중간값으로 자동 설정합니다. 외곽마다 위치를 판단하므로 이미 배열된 파일의 여러 외곽도 지원합니다. 단순한 배열 배치 순서 기능이며 소재 지지 상태나 클램프를 판단하지 않습니다.

내부 홀·포켓은 외곽 전에 가공하며, 수동 지정 외곽 순번을 우선합니다. 수동 순번을 해제하려면 목록 위 `외곽 순서 자동`을 누릅니다. 시계/반시계는 객체 방문 순서이며 개별 윤곽의 Climb/Conventional 절삭 방향을 바꾸지 않습니다. 목록/공구 경로/NC/예상 거리/공구 교체 계획이 같은 순서를 사용하고 설정·작업 파일에 저장됩니다. 구버전 작업은 기존 가까운 순서를 유지합니다. 생성 전 목록과 시뮬레이션을 확인하고 실제 장비에서는 공중 드라이런으로 확인하세요.

## V1.36: 수동 배치의 드래그 시작·복사 반응 개선

수동 배치에서 객체를 누르거나 Ctrl로 선택을 추가/해제할 때 기존 선의 색과 굵기만 바꿉니다. 클릭마다 전체 형상과 공구 오프셋을 다시 그리지 않으며, 선택 경계는 화면 갱신 때 준비하여 재사용합니다. 이동·회전·반전·삭제·되돌리기 이후에는 새 형상 기준으로 갱신합니다. 붙여넣기 때 가공 순서 계산은 반복되는 면적·중심 계산과 확실히 먼 경로 검색을 줄이고 기존 내부 우선·수동 순서·동일 거리의 결정 순서를 유지합니다.

합성 40개 파츠/89,600점의 동일 PC 프로파일에서 마우스 누름 약0.98→0.004초, 복사0.09→0.009초, 붙여넣기13.56→3.93초였습니다. 측정 도구 비용을 포함한 테스트 수치이며 실제 작업과 PC의 속도를 보장하지 않습니다. 가공 설정과 출력 경로는 유지합니다.

## V1.35: 급속 이동 포함 예상 시간

예상 시간은 `(절삭·절입 시간 + 급속 XYZ 거리 ÷ 3,000mm/min) × 1.10 + G4 고정 대기 시간`입니다. 절삭·절입은 기존 계획값과 확인 가능한 NC의 이동 시간 중 큰 값을 사용하며, 프리뷰·START/END의 피드 이동도 반영합니다. 급속은 실제 생성 코드의 상승·접근·파츠 사이 이동에서 계산합니다. 화면과 FULL/ROUGH/FINISH 파일명은 각각 분 단위로 올림합니다. 절삭거리·마모 보정과 출력 동작은 바뀌지 않습니다.

초기 위치는 작업좌표 XYZ 0으로 가정합니다. 실제 위치를 알 수 없는 G53/매크로·좌표계 변경 후 이동, 교체 대기·프로빙·수동 정지는 추가 시간이 필요하다고 표시합니다. G4 P는 초로 가정합니다(장비가 ms 모드이면 실제 대기가 더 짧을 수 있음). 10%는 시간 여유이며 CV/가감속·컨트롤러 처리로 더 오래 걸리지 않는다는 보장은 아닙니다. 3D 재생 시간은 기존 작업좌표 이동만 표시하는 시간으로 유지됩니다.

## V1.34: 사용하지 않는 어니언스킨 잔여량 검사 수정

어니언스킨과 황삭/정삭 분리를 모두 끈 경우 저장된 잔여량이 판 두께 이상이어도 코드 생성/시뮬레이션을 막지 않습니다. 어니언스킨을 사용할 때는 잔여량이 0 이상, 판 두께 미만이어야 합니다. 황삭/정삭 분리에서는 잔여율로 계산한 두께를 검사하며, 미사용 잔여량 입력값은 그대로 보존합니다. 황삭 측면 여유 검사는 별도 오류로 유지합니다.

## V1.33: 프로그램 내부 GPU 뷰어·포켓 보정

V1.33은 3D 시뮬레이션을 프로그램 내부 창에서 엽니다. V1.32의 포켓 치수·마모 보정도 유지합니다.

- 카운터보어 등 아일랜드 포켓에도 내경 치수 보정과 거리 기반 마모 보정을 적용합니다. 내경 `+0.1mm`는 포켓 지름/폭을 0.1mm 확대합니다. 외경 보정은 포켓 내부의 **닫힌 보호 돌출부** 지름/폭에 적용합니다. 판재 밖으로 열린 벽은 폐쇄된 돌출부와 구분되며 외경 보정을 일괄 적용하지 않습니다.
- 마모는 기존 프로파일과 같이 **윤곽 하나의 예상 중간 거리에서 공구 지름을 계산하여 그 윤곽에 고정**합니다. 매 NC 줄마다 지름을 바꾸지는 않습니다. 교체 구간마다 새 공구 기준으로 초기화하고 실제 계획 지름으로 포켓 연결·주변 파츠 간섭을 검사합니다.
- Ø2 공구로 Ø3 관통홀/Ø8 카운터보어를 가공할 때는 STEP 가져오기에서 `단차 면을 아일랜드 포켓으로 가져오기`를 켜고 목록에 포켓이 있는지 확인하세요. 프로파일만 들어온 기존 작업은 자동으로 포켓으로 바뀌지 않습니다. STEP을 다시 가져와야 면 전체를 비우는 경로가 생성됩니다.
- 상단 `3D 시뮬레이션`은 프로그램 내부 GPU 창을 엽니다. 경로와 깊이 버퍼를 한 번 만든 뒤 전환·회전·확대 시 재사용합니다. 브라우저/HTML/별도 서버/추가 런타임 설치를 사용하지 않습니다. GPU 초기화·표시가 실패하면 기존 내부 뷰어를 엽니다. 설정 → `3D 뷰어` → `기본 3D 뷰어 열기`로 직접 선택할 수도 있습니다.
- G53/매크로 내부 이동은 제외하고 복귀점은 ◆로 표시합니다. 깊이맵은 명목 공구 폭을 이용한 근사 표시이며 정밀 잔삭·충돌 시뮬레이션이 아닙니다. Windows GPU의 실제 픽셀 표시·2만 이동의 버퍼 재사용·재생/크기 변경/자원 해제를 확인했습니다. 깊이 범례는 기존 색상을 사용합니다. 실가공은 미검증입니다.

## V1.31: 좌표계 미리보기·날짜 저장·균등 거리 공구 교체

G53 기계좌표와 교체 매크로 내부 이동은 작업좌표 경로에 그리지 않습니다. 알 수 없는 위치에서 다음 작업점까지 임의로 연결하지 않고, 작업좌표가 다시 확인되면 표시를 재개하며 복귀 위치에 ◆를 표시합니다. 기계 이동은 깊이맵/화면 맞춤/재생 시간에서 제외됩니다. G53이 포함된 출력 NC는 그대로 유지됩니다. 기계좌표·매크로의 실제 동작을 검증하는 시뮬레이터는 아닙니다.

처음 작업을 저장하면 `YYYYMMDD_작업.cfrpcam`을 기본 이름으로 제안하며 저장 위치는 사용자가 고릅니다. 이미 열거나 저장한 작업은 같은 파일에 저장됩니다. 원본 DXF/STEP은 덮어쓰지 않습니다.

설정 탭의 `중간 공구 교체`에서 사용 여부와 공구당 최대 가공거리(기본 6.5m), 호출 매크로(기본 M881), 재프로빙 후 기계좌표 복귀 Z(기본 -70), 스핀들 안정 대기(기본 3초)를 설정합니다. 기본은 꺼짐입니다. 설정과 작업 파일에 저장되며 기존 작업 파일을 열면 꺼짐으로 복원됩니다.

18m 작업에 최대 8m를 지정하면 약 6m씩 세 구간으로 나누어 두 번 교체합니다. 실제 경계는 완성된 윤곽 사이이므로 균등값과 차이가 날 수 있으며, 순서/윤곽 길이 때문에 공구 수가 늘 수 있습니다. 한 윤곽 자체가 최대 거리를 넘으면 생성하지 않습니다. 기존 내부 우선과 지정 외곽 순서를 유지하고 마지막에 불필요한 교체를 넣지 않습니다. 생성 전 구간별 거리를 확인하며 8m/10m 경고는 공구별 거리에 적용됩니다. 같은 명목 지름의 새 공구를 사용하고 교체할 때 마모 보정 거리를 초기화합니다.

교체 NC 순서: 가공 안전 Z 상승 → M5/M9 → 교체 매크로 → mm/G90/G54 등 모드 복원 → 기계 Z 복귀 → 설정된 절삭유/스핀들 시작 및 대기 → 다음 가공점 XY 이동 → 접근 Z/절입. START/END 전체나 XY 원점 설정은 중간에 다시 실행하지 않습니다. 매크로 입력은 M881 같은 단일 호출만 허용합니다. M881은 판재 바닥 Z0와 사전 원점복귀를 전제로 하며, 교체 대기·재프로빙·실패 시 NC 중단은 실제 설치된 매크로가 담당해야 합니다. 다른 매크로도 G54 XY 원점을 유지해야 합니다.

일반 가공과 어니언스킨 황삭/정삭 분리 파일을 지원합니다. 단일 파일에서 외곽 황삭 전체 후 정삭을 뒤로 미루는 옵션은 중간 교체와 병용할 수 없습니다. 교체/프로빙 동작은 CAM 3D 시뮬레이션에 재현되지 않고 예상 시간에도 포함하지 않습니다. 실제 Mach3/장비 검증은 미실시이며 최초 사용 전 공중 드라이런이 필요합니다.

화면에서 여러 윤곽을 선택하거나 목록에서 Ctrl/Shift로 여러 행을 선택한 뒤, 목록 위의 `선택 가공 적용` 또는 `선택 가공 미적용`을 누르세요. 선택한 윤곽 전체에 적용하고 선택하지 않은 윤곽은 유지합니다. 미적용은 형상 삭제가 아니며 NC 생성에서 제외됩니다. 선택은 유지되고 Ctrl+Z로 일괄 복원됩니다. 작업 파일에도 가공 여부가 저장됩니다. 기존 가공 여부 셀의 선택창도 열 때의 다중 선택 전체에 적용합니다.

## V1.30: 작업 파일·외곽 삽입선·거리 경고 확인

상단 두 번째 줄의 `작업 저장`/`작업 열기`로 `.cfrpcam` 파일을 저장하고 이어서 편집할 수 있습니다. Ctrl+S 저장, Ctrl+O 열기와 다른 이름 저장을 지원합니다. 형상 자체, 배열과 원본 파츠, 판재/공구/가공 설정, 탭·시작점·외곽 순번, 일반/어니언스킨 START·END를 포함하므로 원본 DXF/STEP 없이 열 수 있습니다. STEP의 원래 3D 모델 편집 상태와 기존 NC, 되돌리기 이력은 포함하지 않으며 NC는 다시 생성합니다. 작업 열기/종료 시 변경된 작업의 저장 여부를 묻습니다. 이 파일은 개인정보나 도면을 포함할 수 있으므로 사용자가 지정한 로컬 위치에만 저장합니다.

외곽 행을 끌면 행 위쪽/아래쪽 절반에 따라 노란 삽입선이 나타납니다. 놓으면 선 위치로 이동합니다. 목록 끝에서는 자동 스크롤하고, ↑/↓ 버튼으로 선택 외곽을 한 칸씩 옮길 수도 있습니다. 내부 우선은 유지합니다. 열 정렬 중 순서를 바꾸면 화면에 보이는 외곽 순서를 기준으로 고정하고 실제 가공 순서 표시로 돌아갑니다.

10m 이상 예상 절삭거리는 자동 차단 대신 매 생성 시 확인 경고를 표시합니다. 기본은 ‘아니요’이며 ‘예’를 누르면 생성합니다. 8m 경고와 다른 경로 검사는 유지하고, 초과 승인 NC에는 경고 주석을 남깁니다. 이는 기계 정지/공구 상태 감시 기능이 아닙니다.

## V1.29: 단축키와 설정 안내

T는 수동탭, S는 시작점 선택을 켭니다. 한 번 지정하면 종료되며 다음 점은 단축키를 다시 누르세요. Esc는 점 선택을 취소하고 Home은 전체 형상을 화면에 맞춥니다. 설정 탭 아래에 기존 방향키·R/F·복사/붙여넣기 등 단축키 안내를 추가했습니다. 문자 단축키는 영문 입력 상태에서 사용하세요. 입력칸 편집이나 별도 창에서는 새 단축키가 CAM 선택 모드를 바꾸지 않습니다.

## V1.28: 외곽 절단 순서 드래그

외곽 행의 `순서` 또는 이름/Layer 영역을 잡아 다른 외곽 행으로 드래그하면 위아래 순서를 바꿀 수 있습니다. 선택한 대상 행이 강조되며 아래로 내리면 그 행 뒤, 위로 올리면 그 행 앞에 절단됩니다. 변경 후 외곽 순번 전체를 고정하므로 최적화가 되돌리지 않습니다. `외곽 순서 자동` 버튼으로 전체 지정을 해제할 수 있습니다. 내부/포켓 행은 이 드래그로 옮기지 않습니다. `지정`/`윤곽`/`가공 여부` 셀은 클릭 편집 영역입니다.

오른쪽 윤곽 목록에서 외부 윤곽의 `지정` 셀을 클릭해 1, 2, 3 등을 입력하고 Enter로 적용합니다. 내부 형상 가공이 끝난 뒤 지정한 외곽 순번대로 절단하며 이동 최적화가 이 순서를 바꾸지 않습니다. 지정하지 않은 외곽은 뒤에 자동 배치됩니다. 같은 번호끼리는 기존 자동 정렬 기준을 사용하므로 정확한 순서는 서로 다른 번호로 지정하세요. 빈칸은 외곽 순번을 해제하며 Ctrl+Z로 복원할 수 있습니다.

목록의 `개체` 열에서 파일 이름과 복사본 #번호를 확인할 수 있습니다(가로 스크롤 지원). 이 번호는 현재 배치의 해당 외곽에 적용되며 원본에서 미리 지정한 뒤 복제하면 순번도 복사되므로 최종 배치 후 각각 지정하세요. 외곽 전용 순번이 없으면 기존 일반 가공 순번 동작을 유지합니다. 일반 NC와 어니언스킨 황삭/정삭 분리 모두 동일한 외곽 순번을 사용합니다.

## V1.27: 배치 스냅 제거·방향키 수정

배치 스냅을 제거하고 Num Lock이 켜졌을 때 방향키가 무시되던 문제를 수정했습니다. 기본 1mm, Shift 0.1mm로 이동합니다. 공구 참고선은 유지합니다.

## V1.26: 패널 폭·다중 선택·스냅·공구 참고선

V1.27에서 배치 스냅을 제거했습니다. 판재 테두리 근처에서도 드래그한 만큼 자유롭게 이동하며 공구 참고선은 유지합니다.

수동 배치 중 `공구 보정경로/순서 표시`를 켜면 공구 지름·내외경 보정을 반영한 주황색 점선 중심선을 표시합니다. 드래그 중 함께 이동하고 공구 지름 변경 시 갱신합니다. 이는 간단한 윤곽 참고선이며 리드인·마모·포켓·전체 충돌 검사는 제외합니다. 일반 모드의 상세 미리보기 및 코드 생성 검사는 유지합니다.

수동 배치에서 Ctrl+클릭으로 개체를 추가 선택하고 다시 Ctrl+클릭하면 해제합니다. 선택된 개체를 드래그하거나 방향키로 움직이면 함께 이동하며, Ctrl+C/V와 Del도 선택 전체에 적용됩니다. 다른 개체를 일반 클릭하면 단일 선택, 빈 곳을 일반 클릭하면 전체 해제합니다. R/F는 선택한 각 개체의 중심을 기준으로 회전/반전합니다.

시작/최대화/창 크기 변경 시 설정 입력칸에 필요한 폭과 화면 크기에 맞춰 좌우 패널을 배분합니다. 긴 설정 설명은 줄바꿈하며, 경계선을 드래그하면 원하는 폭으로 바뀝니다. 조절한 비율은 현재 실행 중 창 크기가 바뀌어도 유지하며 경계선을 더블클릭하면 자동 폭으로 복원합니다. 글자 크기 변경 시에도 자동 폭을 다시 계산합니다. 패널을 너무 좁게 줄이면 가로 스크롤이 나타나며 세로 스크롤은 유지합니다.

## V1.25: 배치 키보드 편집

화면에서 개체를 선택하고 방향키를 누르고 있으면 키 반복에 따라 계속 이동합니다. 기본 반복당 1mm, Shift를 함께 누르면 0.1mm입니다. 키를 놓으면 이동이 멈추며 Windows 키보드 반복 설정에 따라 시작 지연과 속도가 달라집니다. 다중 선택은 상대 위치를 유지합니다. 수동 배치 중 R은 90° 회전, F는 선택 개체 중심 기준 좌우 반전입니다. 내부 윤곽·탭·시작점·포켓도 함께 이동/반전하고 Ctrl+Z로 되돌릴 수 있습니다. 입력란 및 점 지정/드래그 중에는 방향키로 배치를 변경하지 않습니다. 이동·반전 후 판재 범위와 간격을 확인하세요.

## V1.24: 피드·점 선택·개체 편집

우측 상단 선택 수량은 화살표 또는 입력 후 Enter/적용으로 화면에 반영됩니다. 기존 배치를 유지하며 늘린 개수만 옆/위에 임시 배치하고 줄이면 뒤쪽 복사본부터 제거합니다. 0은 해당 파츠를 화면에서 제외하며 다시 늘릴 수 있습니다. 자동 회전/촘촘한 탐색은 실행하지 않습니다.

화면에서 윤곽을 선택한 뒤 Del을 누르면 구멍까지 포함한 해당 개체가 삭제됩니다. Ctrl+C / Ctrl+V는 현재 CAM 작업 내부에서 선택 개체를 복사/붙여넣으며, 다중 선택의 상대 위치와 시작점·수동탭을 보존합니다. 수동 어레이 선택도 지원하고 입력란의 문자 편집에는 영향을 주지 않습니다. Ctrl+Z로 수량 변경·삭제·붙여넣기를 되돌릴 수 있습니다. 추가 복사본은 최적 배치가 아니며 판재 밖 개수를 상태줄에 표시하므로 자동/수동 어레이로 정리한 뒤 가공 코드를 생성하세요.

판 두께에 따라 2T F600, 3T F550, 6T F500을 표시합니다. `추천 피드 적용` 버튼을 누를 때만 Feed XY에 반영하므로 두께 변경이나 설정 불러오기로 기존 피드를 덮어쓰지 않습니다. 다른 두께는 임의 보간하지 않습니다. Ø2·24000rpm·전 깊이 기준의 사용자 지정 시험값이며 공구/RPM/패스 설정을 자동 변경하지 않습니다.

절삭 시작점과 수동탭은 유효한 점을 한 번 선택하면 OFF가 됩니다. 다시 지정하려면 버튼을 다시 누르세요. XY 원점은 기존대로 1회 선택이며, 거리 측정과 두 선 연결도 두 번째 선택 완료 후 OFF가 됩니다. 잘못 클릭해 작업이 성립하지 않은 경우에는 선택 모드를 유지합니다. 수동 어레이 편집 중 점 선택 버튼을 누르면 드래그 편집을 종료합니다.

원본에 수동탭을 지정한 후 어레이하면 각 복사본의 같은 상대 위치에 탭이 복사됩니다. 회전해도 함께 따라가지만, 어레이한 뒤 특정 복사본에서 탭을 수정한 내용이 나머지 복사본에 자동 전파되지는 않습니다. 어니언스킨 황삭/정삭 분리 모드에서는 탭을 출력하지 않습니다.

## V1.23: 내경·외경 치수 보정

공구 설정에 `내경 치수 보정 (mm)`와 `외경 치수 보정 (mm)`를 추가했습니다. 지름/전체 폭 기준으로 양수는 확대, 음수는 축소하며 실제 중심 경로는 절반만 이동합니다. 현재 요청에 따른 초기 시험값은 내경 +0.10mm, 외경 -0.14mm이며 0으로 바꾸면 해당 보정을 끕니다. 입력값은 설정에 저장됩니다. 새 항목이 없는 기존 설정에도 이 초기값이 표시되므로 생성 전에 확인하세요.

닫힌 내·외곽 윤곽의 미리보기, 안전검사, 황삭·정삭 및 NC 생성에 적용하며 NC 헤더에 보정값을 기록합니다. 열린 선은 제외합니다. V1.31 배포본은 별도 포켓도 제외하며, V1.32의 포켓 적용 범위는 문서 맨 위를 참조하세요. 원본 형상·공구 지름·기존 마모 보정률은 변경하지 않고, 마모를 계산한 실제 공구 지름에 치수 보정을 별도로 적용합니다. 치수 보정 변경 시 저장/시뮬레이션용 G-code를 다시 생성합니다. 시험 NC에 적용하는 기능이 아니라 CAM의 일반 설정 기능입니다. 실가공 치수 개선은 아직 미검증입니다.

## V1.22: 촘촘한 윤곽 배열

`촘촘한 배열 (실제 윤곽 / 180° 엇갈림)`을 체크하면 네모 박스 대신 닫힌 외곽의 빈 공간을 활용합니다. 기본 0°/180°, 90° 회전 허용 시 0°/90°/180°/270°, 자동 회전 최적화 시 5° 단위로 탐색합니다. 거울 반전은 하지 않으며 구멍 내부에는 다른 파츠를 넣지 않습니다. 체크를 끄면 기존 빠른 박스 배열입니다.

객체 목록에서 파츠를 선택하고 `선택 파츠 외곽 여유 (mm)`를 입력한 뒤 `여유 적용` → `판재에 자동 어레이` 순서로 사용합니다. A=1mm, B=2mm면 실제 외곽 사이 최소 3mm를 확보합니다. 같은 파츠의 복사본은 같은 값을 사용합니다. 빈칸은 공통 가공물 간격의 절반이며, 명시한 파츠별 값에 공통 간격을 다시 더하지 않습니다. 판재 경계에서는 가장자리 여유에 해당 파츠의 외곽 여유를 더합니다.

외곽 여유는 배치용으로 원본 치수나 가공 보정을 변경하지 않습니다. 기존 배치에는 자동 적용되지 않으므로 변경 후 다시 배열하세요. 파츠별 값은 현재 작업과 되돌리기에 보존되고, 원본 파일을 새로 불러오면 기본값으로 시작합니다. 배열 모드 자체는 프로그램 설정에 저장됩니다. 수동 배열에는 적용되지 않습니다.

공구 지름·황삭 여유에 비해 작은 간격은 배치 전에 경고합니다. 실제 가공 경로 검사는 G-code 생성 시 별도로 유지됩니다. 닫히지 않거나 유효하지 않은 형상은 먼저 복구해야 합니다. 계산 중 취소할 수 있고, 실패·취소 시 기존 배치를 유지합니다. 전체 최적 배치를 보장하는 방식은 아니며, 복잡한 형상·많은 수량·5° 탐색은 느릴 수 있습니다. 단일 객체 수량 0은 최대 1000개까지 탐색합니다. 실제 6T 암 원본과 실가공은 미검증입니다.

## V1.22: 어니언스킨 황삭/정삭 분리

`어니언스킨 황삭/정삭 파일 분리`를 켜고 일반 G-code 생성·저장을 사용하면 `_ROUGH.nc`와 `_FINISH.nc`가 생성됩니다. 기존 선택 윤곽 PART1/2 버튼은 제거했습니다. 분리 시 바닥 잔여율은 기본 10%이며, 6T는 5.4mm까지 황삭하고 0.6mm를 남깁니다. 전체 닫힌 윤곽에 설정된 측면 정삭 여유를 적용하고 마이크로탭은 넣지 않습니다. 기존 `어니언스킨 잔여(mm)`와 정삭 적용 범위는 단일 파일 모드용입니다.

FINISH는 같은 지름의 새 공구로 실행합니다. XY 원점·소재 고정을 유지하고 Z만 다시 설정하세요. 각 파일은 마모거리 0m부터 계산하며 8m 경고/10m 차단과 예상시간은 파일별로 적용됩니다. 포켓·열린 선 등 별도 마무리가 없는 경로는 ROUGH에만 포함됩니다. 정삭 파일은 내부 형상을 외곽보다 먼저 완료합니다.

두 파일의 START/END는 기본적으로 기존 코드를 사용합니다. `어니언스킨 START / END` 탭에 전용 코드를 입력하면 **FINISH 파일만** 해당 코드를 사용합니다. START와 END는 각각 비워두면 기존 값을 사용하고, 분리를 꺼도 입력 내용은 보관됩니다. 마이크로탭 없이 관통하므로 마지막 절삭까지 별도 고정이 필요합니다. 실가공은 미검증입니다.

## V1.21 3D 표시 성능·공구거리 보호

3D 시뮬레이션의 깊이맵/공구경로 전환과 급속선 표시 변경은 이미 만든 Canvas 경로를 재사용합니다. 카메라·확대·이동·창 크기가 바뀔 때만 화면 경로를 다시 계산합니다.

마모 보정 입력은 `10m당 지름 감소량`이며 기본값은 D2.00 공구가 11.44m 가공 후 D1.91로 측정된 결과를 반영한 `0.079mm/10m`입니다. 예상 절삭거리 8m 이상은 확인 경고를 표시하고 10m 이상은 G-code 생성을 차단합니다. 2분할은 각 파일 시작 시 새 공구를 쓰는 START G-code 기준으로 PART1·PART2를 따로 판정합니다.

기존 누적거리·누적시간 입력은 제거했습니다. 분할 파일명에는 전체 시간이 아니라 PART1·PART2 각각의 예상시간이 표시됩니다. 기존 100m당 사용자 지정 마모값은 10m 단위로 자동 변환됩니다.

## V1.20 경로 허용오차 기본값 변경

어니언스킨과 황삭 후 벽면정삭은 기본 OFF입니다. V1.18 이하 설정으로 처음 실행할 때도 OFF로 전환하며, 이후 직접 켠 설정은 저장됩니다.

V1.19 이하에서 저장한 기존 기본값0.02mm도 0.01mm로 전환합니다. 그 외 사용자 지정값은 유지합니다.

`경로 허용오차` 기본0.01mm로 짧은 G1 선분을 줄입니다. 0이면 비활성, 허용 범위0~0.1mm입니다. 이 값은 기존 CAM 경로 대비 추가 단순화 오차이며 STEP/DXF 원본 변환 오차 및 기계 CV 오차와 별개입니다. 10도 이상 방향 전환과 탭 높이 변화는 유지합니다. 원호를 새 G2/G3로 복원하는 기능은 아닙니다.

`포켓 연속 가공` 기본 ON입니다. 양각을 피하면서 같은 깊이의 경로를 G1으로 연결하고, 다음 깊이도 비워진 영역에서 연결 가능하면 Z를 올리지 않습니다. 인접 경로로 새로 절삭하는 연결은 스텝오버 이내로 제한하고 긴 연결은 이미 비운 영역을 이용합니다. 분리 영역/보호 양각 때문에 검증할 수 없으면 상승합니다. OFF는 각 경로를 안전 높이로 분리합니다. 생성 NC 기반 3D 시뮬레이션에서 실제 연결을 확인할 수 있습니다.

연속 경로의 추가 XY 이동 때문에 Z 상승이 줄어도 가공시간이 항상 줄지는 않습니다. 미리보기의 청록색 기본 경로와 생성 NC의 연결 경로를 구분하세요. NC를 다시 생성하고 첫 실가공 전에 공중 운전으로 확인하세요.

Mach3의 CV, LookAhead, 가감속 설정은 CAM에서 변경하지 않습니다. 짧은 선분/작은 CV 허용오차/Exact Stop은 별도로 감속에 영향을 줄 수 있습니다. [Mach3 CV 공식 설명](https://www.machsupport.com/wp-content/uploads/2013/02/Mach3_CVSettings_v2.pdf)

## V1.18 기본 Z 높이

`안전 Z 자동: 판 두께 × 2` 기본 ON입니다. 소재 윗면에서 두께의 2배 위로 올라가 XY 이동하고, 소재 윗면 +1mm까지 급속 접근 후 Plunge로 절입합니다. 두께3mm의 TOP 좌표는 안전Z6/접근Z1, BOTTOM 좌표는 안전Z9/접근Z4입니다.

자동을 끄면 안전 Z를 직접 입력할 수 있습니다. 두께0.5mm 미만에서 접근 여유1mm를 유지하려면 자동을 끄고 안전 Z를 1mm 이상으로 설정하세요. 기존 NC는 다시 생성해야 합니다.

## V1.17 급속 접근

`안전 Z`는 부품 사이 XY 이동 높이입니다. `급속 접근 여유` 기본1mm까지 Z만 급속 하강한 뒤 설정 Plunge 속도로 절입합니다. 접근 여유는 0보다 크고 안전 Z 이하여야 합니다.

TOP 기준 안전 Z10/접근1이면 `G0 Z10 → G0 X… Y… → G0 Z1 → G1 Z… F…` 순서입니다. BOTTOM 기준 판 두께3mm라면 안전 Z13/접근 Z4로 계산합니다. 포켓도 최상단 소재 표면을 기준으로 접근합니다.

기존 NC는 재생성해야 반영됩니다. 가공 전 시뮬레이션과 공중 운전으로 원점·소재 상면을 확인하세요.

일반 G코드 저장이 완료되면 알림창에 저장된 파일 경로를 표시합니다. 2분할 저장은 기존 안내창을 유지합니다.

## V1.15 STEP 투영 수정

방향 회전이나 원점 이동 뒤 발생하던 STEP 외곽 투영 오류를 수정했습니다. 홀 사이 긴 선처럼 나타나던 가짜 내부 윤곽도 수정했습니다. 기존 작업은 STEP을 다시 가져와야 반영됩니다. 실제로 분리된 형상은 계속 차단합니다.

## V1.14 목록에서 가공 적용/제외

윤곽 목록의 **가공 여부** 셀을 클릭해 **적용 / 제외**를 선택하면 즉시 반영됩니다. 별도의 설정 적용 버튼은 필요하지 않습니다. Ctrl/Shift로 여러 행을 고른 뒤 선택된 행의 가공 여부 셀을 일반 클릭하면 일괄 변경합니다.

제외한 행은 회색·순서 `-`로 남고 NC에서 빠집니다. 같은 셀에서 적용으로 복원하거나 Ctrl+Z/Ctrl+Y로 되돌릴 수 있습니다. 왼쪽 `이 윤곽 가공에 포함`과 연동되며, `안전검사 제외`와 별개의 설정입니다. 변경 뒤 NC 저장/시뮬레이션 시 기존 코드의 변경 여부를 검사합니다.

## V1.13 아일랜드 포켓

1. STEP을 다시 열고 방향·원점을 정합니다. `단차 면을 아일랜드 포켓으로 가져오기`를 켠 채 가져옵니다(기본 ON, 설정 저장).
2. 단차 면은 목록에서 `아일랜드 포켓`으로 표시되고 청록색 다중 경로가 보입니다. 필요 없는 작업은 `가공 포함`을 끄세요.
3. 기본 스텝오버 40%, 패스 깊이 0.25mm, 정삭 여유 0.1mm입니다. 각 깊이에서 황삭 후 경계 정삭을 수행합니다. 정삭 Feed는 XY Feed의 80%입니다. 스텝오버 허용 범위는 1~50%입니다.
4. 포켓(얕은 순) → 기존 홀/프로파일 순서로 출력합니다. 포켓은 수동 프로파일 순번보다 먼저이며, 전체 외곽은 기존 순서 설정을 따릅니다.
5. Z0은 양각 최상단입니다. 모델의 단차 깊이를 자동 사용하며, 가져온 바닥보다 깊게 변경할 수 없습니다. 포켓은 Full-depth 옵션과 관계없이 포켓 패스 깊이를 사용합니다.

각 오프셋 경로 사이에는 안전 Z로 상승 후 XY 이동합니다. 판 가장자리로 열린 포켓은 공구가 판 외부로 나가므로 고정구와 여유 공간을 확인하세요. 다른 배열 부품을 침범하는 포켓은 NC 생성을 차단합니다.

첫 구현은 **수평 바닥·수직 벽인 2.5D STEP** 대상입니다. 경사면/필렛 등 3D 가공이 필요하면 포켓 가져오기를 끄고 별도 CAM을 사용하세요. V1.31 배포본에서는 포켓 작업의 거리 기반 공구 마모 보정을 꺼야 합니다. V1.32는 이 제한을 해제하며 적용 방식은 문서 맨 위를 참조하세요. 급속 연결 최적화·헬리컬 진입·잔삭 공구 교체는 아직 지원하지 않습니다. 포켓은 해당 공구가 수직 진입 가능한 소재/조건에서만 사용하세요.

공구 반경 때문에 가공할 수 없는 모서리와 약간의 계산 안전 여유는 잔여 면적으로 경고합니다. 경고는 자동 잔삭 완료를 뜻하지 않습니다. 공구를 줄여 다시 계산하거나 별도 마무리가 필요합니다. 표시 가공거리는 포켓 절삭을 포함하며, V1.35 예상 시간은 알려진 급속 XYZ 이동과 10% 여유를 포함합니다. 교체·프로빙·알 수 없는 기계 이동은 별도입니다.

## V1.12 소스 업데이트

- STEP 가공면은 방향을 정하며, 외곽은 선택한 면이 속한 전체 바디 투영으로 가져옵니다. 양각 경계가 외곽 절단선에 섞이지 않습니다.
- 같은 바디의 여러 면을 선택해도 부품은 한 번만 가져옵니다. 다른 바디는 자동 포함하지 않습니다.
- STEP Z0은 선택 바디의 **최상단**이며, 두께는 최상단부터 바닥까지입니다. 양각 주변을 제거하는 면 포켓 가공은 자동 생성하지 않습니다.
- `가공 전 외곽 프리뷰 1회`를 켜면 START 코드 후, 절삭 전에 현재 작업의 활성 외곽을 한 번씩 따라갑니다. 외곽이 없는 홀 전용 분할 파일은 활성 형상의 경계 사각형을 따라갑니다.
- 기본 높이는 소재 최상단 위 30mm, 속도는 1000mm/min입니다. 높이·속도를 변경하고 설정에 저장할 수 있습니다. 프리뷰 높이는 안전 Z 이상이어야 합니다. Bottom 원점에서는 두께를 더합니다.
- 프리뷰는 명목 외곽선이며 공구 반경·리드인·클램프 간섭 검증을 대신하지 않습니다. START 코드의 스핀들/M8 상태를 유지합니다. 이동 후 원점 XY로 돌아와 기존 가공 순서를 시작합니다. 절삭거리·공구 마모에는 프리뷰 이동을 더하지 않습니다.
- 기존 설정에는 기본 OFF로 추가됩니다. 사용할 때 체크하세요. 자동 업데이트 배포 버전은 검증된 `latest.json`을 따릅니다.

# CFRP Router CAM

Mach3용 CFRP 2D/2.5D CAM 프로그램의 공식 배포 및 업데이트 저장소입니다.

## 최신 버전 다운로드

[CFRP_Router_CAM.exe](https://github.com/wofidkr57-jpg/CFRP-Router-CAM/releases/latest/download/CFRP_Router_CAM.exe)

현재 최신 버전은 **V1.44**입니다.

- 어레이 전에 지정한 윤곽 가공 순서를 모든 복사본에 유지
- 거리 기반 공구 마모 보정: 현재 작업의 절삭거리를 기준으로 윤곽마다 가정 공구 지름을 단계적으로 감소. `10m당 지름 감소량` 기본값은 실측치 기반 `0.079mm/10m`
- 예상 절삭거리 8m 이상은 확인 경고, 10m 이상은 G-code 생성 차단. 2분할은 PART2 전에 공구를 교체하는 전제로 PART1·PART2를 각각 판정
- 설정 파일 없는 첫 실행에서 언어 선택창이 숨는 문제 수정
- NC 파일명에 판재 두께 추가: `260831_2.0endmill_T3.0_panel_12_35min.nc`
- 두 파일로 나누면 `..._PART1.nc`, `..._PART2.nc`로 저장
- 여러 원본 파일을 불러오면 원본 이름 대신 `multi` 사용
- 실제 Python 소스, 검사 코드, Windows 빌드 방법을 저장소와 릴리스에 포함

한국어/영어 UI, NC 영문 전체 가공조건 헤더, 탭 설정 버튼 배치는 유지됩니다.

V1.07부터 프로그램을 시작할 때 새 버전을 확인합니다. 사용자가 업데이트를 승인하면 새 EXE를 내려받아 SHA-256을 검증하고, 기존 프로그램 종료 후 실행 파일을 자동으로 교체합니다. 다운로드나 검증에 실패하면 기존 EXE는 변경하지 않습니다.

## 설정과 최초 실행

설정 또는 언어 선택이 없으면 첫 실행에 한국어/English 선택창이 표시됩니다. 선택 후 메인 화면이 열리고, `settings.json`이 EXE 옆에 자동 저장됩니다. 쓰기 권한이 없으면 기존 방식대로 AppData의 `CFRP_Router_CAM` 폴더를 사용합니다. 기존 `settings.json`은 업데이트해도 보존됩니다. 관리자 권한은 필요하지 않습니다.

## 소스 코드

- [소스 코드](cfrp_router_cam.py)
- [V1.44 소스 패키지](https://github.com/wofidkr57-jpg/CFRP-Router-CAM/releases/download/v1.44/CFRP_Router_CAM_V1.44_source.zip)
- GitHub의 **Code → Download ZIP** 또는 릴리스의 **Source code**에도 실제 소스가 포함됩니다.

Windows Python 3.12 (Tkinter 포함)에서 실행합니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe cfrp_router_cam.py
```

검사 및 EXE 빌드:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s verification -p "test_*.py" -v
.\.venv\Scripts\python.exe verification/gui_smoke_v110_first_run.py ko
.\.venv\Scripts\python.exe verification/gui_smoke_v110_first_run.py en
.\.venv\Scripts\python.exe verification/gui_smoke_v110_first_run.py close
.\.venv\Scripts\python.exe verification/gui_smoke_v108.py
.\build_windows.ps1
```

빌드 결과는 `dist/CFRP_Router_CAM.exe`입니다. GUI 검사는 잠깐 테스트 창을 띄우고 자동으로 닫습니다. 배포용 ZIP에는 개인 `settings.json`, NC 작업물, 인증정보를 넣지 않습니다.

버전별 변경 내역은 [CHANGELOG.md](CHANGELOG.md)를 참고하세요.
